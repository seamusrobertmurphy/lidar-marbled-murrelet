# Movebank nests

Nest locations of radio-tracked marbled murrelets in Clayoquot Sound, 2000 to 2002, file `CS_nests.csv` from the data package Cooke F, Lank DB, Bradley RW, et al. 2022. Data from: Study "Marbled Murrelets at Clayoquot Sound, British Columbia, Canada (2000-2002)". Movebank Data Repository. https://doi.org/10.5441/001/1.kg210889

The file is fetched by the `nests` chunk from https://datarepository.movebank.org/server/api/core/bitstreams/1504af80-ae53-4e69-a6f6-3b2ce5d53958/content. Licence CC0 1.0, as stated in the package README. Only ground-truthed nests are included, with a positional error of about 50 m. The raw file is not committed.
