# Freshwater Atlas coastline

Coastline of the Freshwater Atlas of British Columbia, layer `WHSE_BASEMAPPING.FWA_COASTLINES_SP`, from the BC Data Catalogue record https://catalogue.data.gov.bc.ca/dataset/freshwater-atlas-coastlines. Licence Open Government Licence British Columbia, per that record, read 2026-10-21.

The `fig-study-area` chunk fetches the lines inside the map frame from the provincial web feature service https://openmaps.gov.bc.ca/geo/pub/wfs and saves them as `coastline.gpkg`, which is not committed.
