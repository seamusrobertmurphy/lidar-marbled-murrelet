# Inputs

Each dataset sits in its own folder under `02.inputs/` with a README giving its source, licence, retrieval date and download link. The manuscript chunk that reads a dataset repeats that name and link in the comment directly above the read. `derived/` holds files the manuscript builds from them.

| Folder | Dataset | Role | Source |
|---|---|---|---|
| `movebank/` | Clayoquot Sound nests, 2000 to 2002 | presence records | https://doi.org/10.5441/001/1.kg210889 |
| `lidarbc/` | LidarBC 2019 point clouds | forest structure | https://lidar.gov.bc.ca/ |
| `ntems/` | Canada Forest Harvest 1985-2022 | harvest screen | https://opendata.nfis.org/mapserver/nfis-change_eng.html |
| `fwa/` | Freshwater Atlas Coastlines | study area map | https://catalogue.data.gov.bc.ca/dataset/freshwater-atlas-coastlines |
| none, read through the rnaturalearthhires package | Natural Earth 1:10 million admin 0 countries | locator inset | https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/ |
